## Ejecutar las pruebas

```bash
cd testing-jest-junit-examen/javascript-jest
npm install
npm test
```

```bash
cd testing-jest-junit-examen/java-junit
mvn test
```

Requisitos: Node.js/npm, JDK 17+ y Maven.
